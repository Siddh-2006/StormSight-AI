## Known gaps (deliberately not papered over)

- **Regional-language CAP alerts.** Auto-translating alert text without picking a real translation approach and a real language list would mean silently faking a claim. `backend/app/api/cap_format.py`'s own docstring says so.
- **The conformal calibrator isn't fitted on real data yet.** It's a real, tested piece of code (`backend/app/ml/calibration.py`), but "calibrated" only becomes true once it's fit on a genuine held-out calibration set — which needs either more synthetic episodes set aside specifically for this, or real data. Tracked, not hidden.
- **Source dropout and the availability mask aren't the default training path.** They exist as real, tested, opt-in utilities. Wiring them into `train.py` by default is the natural next step but changes what every future training run produces, which is a call worth making deliberately rather than as a side effect of a documentation-alignment pass.
